# Orange Pixel Dungeon

Orange Pixel Dungeon is a fork of [Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) v4.0.2. It's the normal game with some new artifacts, talents and spells, new and reworked trinkets, balance changes with a lot of love.


## Download

Builds are on the [releases page](https://github.com/NuocCam/orange-pixel-dungeon/releases/latest). Each release has an Android .apk, a desktop .jar and an iOS .ipa.

## Info
- This project DOES use AI-Generation for some assets and codes, however I guaranteed you all experience is original (unless those I already credited) and I put a lot of human works in it, this project is the love of my life and updates is guaranteed.
- If you have any suggestions, bugs report feel free to create them [here](https://github.com/NuocCam/orange-pixel-dungeon/issues)
- You can contact me at discord via my username (_nuoccam)
